# 软件测试报告

本系统当前输入包括工件尺寸、材料、刀具参数、加工参数和刚度矩阵文件；输出包括后端计算得到的壁厚误差、前端误差曲线、发送给 Unity 的材料去除预览 payload，以及当前占位/轻量实现的补偿建议。

本报告基于当前代码链路梳理与静态检查结果编写，重点说明各功能的小项目完成情况；未接入真实实现、仍写死或仅占位的部分会如实标注。

# 刚度矩阵导入与解析测试

该功能负责读取刚度矩阵文件，将刚度值转换成前端 `KeyPoint`，并生成后端可解析的 `K/J/I` 测点 id。当前文件只记录刚度值，不记录坐标，坐标由后端根据工件尺寸补齐。

| 序号 | 类别 | 项目 | 完成结果 |
| --- | --- | --- | --- |
| 1 | 文件读取 | UTF-8 文件读取 | 已完成 |
| 2 | 文件读取 | GBK 文件读取 | 已完成，读取失败时会尝试 GBK |
| 3 | 文件格式 | 单个二维刚度矩阵 | 已完成，例如一行六列表示一条走刀上的 6 个测点 |
| 4 | 文件格式 | 多行矩阵 | 已完成，行对应 J，列对应 K |
| 5 | 文件格式 | 多个二维矩阵 | 已完成，用空行分隔，不同矩阵对应 I |
| 6 | id 生成 | 按 K/J/I 生成 id | 已完成，例如 `K1_J1_I1` |
| 7 | 数据校验 | 非正数、空文件、行列不一致检查 | 已完成，会抛出解析错误 |
| 8 | 坐标字段 | 前端解析后坐标 | 部分完成，前端初始填 `0`，真实坐标由后端返回后覆盖 |
| 9 | 上传入口 | 属性面板上传刚度矩阵 | 已完成 |
| 10 | 上传入口 | 任务流上传刚度矩阵 | 已完成，与属性面板共用同一份 store 状态 |
| 11 | 调试输出 | 前端输出 id/stiffness | 已完成，使用 `console.debug`，Chrome 默认可能需要打开 Verbose 级别 |
| 12 | 历史记录 | 已上传刚度文件版本管理 | 未完成 |

# 后端壁厚误差预测测试

该功能负责接收前端参数和刚度矩阵，完成坐标补齐、切削力预测、傅里叶标定、稳态求解和壁厚误差计算。当前主链路已跑通，参考脚本已拆分进后端正式模块，原参考文件只保留为静态参考。

| 序号 | 类别 | 项目 | 完成结果 |
| --- | --- | --- | --- |
| 1 | API | `/prediction/wall-error` 接口 | 已完成 |
| 2 | API | 请求/响应 schema | 已完成，定义在 `backend/app/schemas/prediction.py` 和 `machining.py` |
| 3 | 坐标补齐 | 解析 `K{k}_J{j}_I{i}` | 已完成 |
| 4 | 坐标补齐 | 根据工件尺寸补 `x/y/z` | 已完成 |
| 5 | 切削力模型 | 机理切削力计算 | 已完成，复现在 `mechanistic.py` |
| 6 | 切削力模型 | 切削力系数来源 | 占位实现，`Ktc/Krc/Kte/Kre` 等仍为后端默认写死值 |
| 7 | 傅里叶标定 | ae 的 +/-25% 采样 | 已完成 |
| 8 | 傅里叶标定 | 线性傅里叶模型 | 已完成，复现在 `fourier.py` |
| 9 | 稳态求解 | 单自由度固定点求解 | 已完成，复现在 `steady_state.py` |
| 10 | 模态质量 | 由刚度、阻尼比、频率反算质量 | 已完成，公式为 `m = k * 1000 * (1 - xi^2) / (2*pi*f)^2` |
| 11 | 模态参数 | 阻尼比、固有频率来源 | 占位实现，当前在 `prediction_service.py` 写死为 `0.0083` 和 `60.5 Hz` |
| 12 | 误差计算 | 局部 SLE / 壁厚误差计算 | 已完成，定义在 `wall_error.py` |
| 13 | 输出结果 | 返回每个测点 `x/y/z/stiffness/error` | 已完成 |
| 14 | 调试日志 | 输出坐标-刚度对应关系 | 已完成，日志名 `prediction.coordinate_stiffness` |
| 15 | 调试日志 | 输出刚度-质量对应关系 | 已完成，日志名 `prediction.stiffness_mass` |
| 16 | 调试日志 | 输出最终误差 | 已完成，日志名 `prediction.wall_errors` |
| 17 | 性能处理 | 长耗时任务异步化/任务队列 | 未完成，当前为同步 HTTP 请求 |
| 18 | 自动测试 | 算法数值单元测试 | 未完成，目前主要通过链路运行和人工核对 |

# 总体结论

当前系统已经完成从“参数输入 -> 刚度矩阵上传 -> 后端壁厚误差计算 -> 前端曲线展示 -> Unity 预览 payload 打包 -> Unity 完成回调 -> 补偿建议”的主链路闭环。主要未完成内容集中在真实 Unity 侧材料去除与误差映射、真实补偿算法、数据库/Redis/认证/部署、自动化测试和部分算法参数配置化。
