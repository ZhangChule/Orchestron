# backend 后端启动

```Bash
conda activate thinwall-dt
cd backend

uvicorn app.main:app --reload --port 8000
```

# frontend 前端启动

```Bash
cd frontend

npm run dev
```

然后浏览器打开 http://localhost:5173

# 后端框架

后端使用python语言（版本python=3.11），先用conda或者venv构建虚拟环境，并创建后端文件夹backend。后端部分的文件结构可以让ai帮忙生成，然后在具体的文件内编写对应的代码就可以

安装的库包括：
```Bash
fastapi==0.128.0
uvicorn[standard]==0.40.0
pydantic==2.12.5
numpy==2.4.4
python-multipart==0.0.22
```

# 前端框架

前端框架要先安装node.js，安装完之后在和backend同级的文件夹下运行命令行窗口

```bash
npm create vite@latest frontend -- --template react-ts

cd frontend
npm install
npm run dev
```

# 前端拆分

App.tsx 从约 2148 行降到 547 行，现在主要负责状态、任务流、接口占位调用和顶层布局。
新增模块：
frontend/src/app/：类型、常量、主题
frontend/src/utils/：尺寸解析、刚度文件解析、本地预测、本地补偿、数字格式化
frontend/src/components/ui/：通用输入框、数据行、玻璃面板、文件标签等
frontend/src/features/navigation/：加工导航树
frontend/src/features/preview/：Three.js 预览、浮动工具条、加工状态浮窗
frontend/src/features/properties/：右侧属性面板
frontend/src/features/tasks/：任务流程和结果指标

# 前端修改

举例：如果你要给刀具新增 rakeAngle 前角字段，通常要改：

types.ts：ToolParams 加 rakeAngle: string
constants.ts：DEFAULT_TOOL 和 CASE_TOOL 加默认值
PropertiesPanel.tsx：刀具属性区域加一个 NumberField
machiningStore.ts：validateTool() 里解析、校验，并映射成后端字段，比如 rake_angle
TasksPanel.tsx：如果它是必填项，在 isToolReady() 加判断
MachiningStatusOverlay.tsx：如果状态浮层也要显示，加一行 DataRow
